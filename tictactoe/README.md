## Tic Tac Toe Validator

* 3x3 grid
* Players: X/O
* First players gets 3 in a row wins

**Task:** implement a validator to determine if a grid is in a winning state or not.

**input:** snapshot grid

**output:** "X wins" / "O wins" / "Draw"

Some examples:
```
Draw
XOO
---
X--

Draw
XOO
---
---

Draw
---
---
---

X wins
XOO
X--
X--

O wins
XOO
-OX
XO-
```
