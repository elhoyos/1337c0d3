## Rover

Build a rover that can be controlled by the keyboard.

The rover can move to the left, right, up or down, one position at a time.

A rover lives on an unlimited grid and starts at position (0, 0).

The CLI should display the position of the rover after moved.

When the user hits "h" a help should be printed.


### Variations

- Grid has limits
- Grid has obstacles
- Multiple rovers
